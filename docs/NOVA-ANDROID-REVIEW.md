# Сравнение с Nova-Android

Проверено 15 ноября 2026 года по [исходникам Nova-Android](https://github.com/confeden/Nova-Android) и её README. Описание возможностей проекта не заменяет проверку на сети конкретного оператора.

| Компонент | Nova-Android | PrivetZapret Android сейчас |
|---|---|---|
| Маршрут приложений | VPN-интерфейс, tun2proxy и несколько удалённых путей | VPN-интерфейс, hev-socks5-tunnel и локальный ByeDPI |
| Пути выхода | WARP/AmneziaWG, MASQUE/QUIC, Opera VPN, выбираемый Proton VPN; импорт VLESS/REALITY и AmneziaWG | Прямое соединение к сайту; удалённого выхода нет |
| DNS | DoH/DoT и правила для приложений | Личный DoH/DoT с явным резервным DoH |
| Проверка | Активные пробы полезного трафика и восстановление после смены сети | Проверка DNS при старте; в этой версии добавлена HTTPS-проба через локальный движок и повтор после смены сети |

Источники: [README Nova](https://github.com/confeden/Nova-Android#принцип-работы), [NovaVpnService](https://github.com/confeden/Nova-Android/blob/main/app/src/main/java/com/example/nova/NovaVpnService.kt), [nova-core](https://github.com/confeden/Nova-Android/tree/main/nova-core), [TunnelStallDetector](https://github.com/confeden/Nova-Android/blob/main/app/src/main/java/com/example/nova/TunnelStallDetector.kt).

## Что это означает для Telegram и TikTok

Прямое соединение через ByeDPI может помочь при фильтрации TLS/QUIC, но не заменяет удалённый выход при блокировке адреса или ограничении по региону. Telegram может обращаться к своим серверам по известным IP без DNS. TikTok использует много доменов и может применять правила по IP, SIM и учётной записи. Проверка `telegram.org` либо `tiktok.com` не доказывает работу мобильных приложений, их медиа или звонков.

Поэтому следующий функциональный этап — удалённый маршрут внутри **того же** Android VPN-сервиса, с собственными или явно выбранными пользователем входами и с измерением реальной загрузки. Перенос всего ядра Nova в текущий APK без интеграции, проверки лицензий и тестирования не является небольшим изменением: у Nova отдельные Go/системные библиотеки и несколько протоколов. Используем её архитектурный принцип и не выдаём локальный режим за полный аналог.

Для проверки на телефоне записывать отдельно: оператор и сеть; DNS-профиль; Telegram сообщения/медиа/звонки; TikTok лента/видео; результат кнопки «Проверить HTTPS». Не собирать личные DNS-ссылки, ключи или историю посещений.
