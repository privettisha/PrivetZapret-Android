# PrivetZapret Android

Android-приложение для локального обхода DPI и подключения личного DNS через DoH/DoT. Без root. Интерфейс в стиле PrivetZapret: три вкладки, одна кнопка подключения.

**Экспериментальная beta, Android 8.0+.** Приоритет проверки: Telegram, YouTube и TikTok. Это направления разработки, а не обещание доступности каждого приложения у каждого оператора. Сетевые проверки на эмуляторе не подтверждают обход российских ТСПУ.

**Если Telegram или TikTok не работают:** текущая версия использует локальную обработку без удалённого выхода. Блокировку IP, ограничение TikTok по региону или полное прекращение передачи данных обычный маршрут не устранит. Telegram теперь может использовать отдельный локальный SOCKS5/WebSocket-прокси; его нужно включить в самом Telegram. Значок «подключено» означает, что VPN-интерфейс запущен. На главной нажмите «Проверить HTTPS»: ответ означает передачу данных через локальный ByeDPI к контрольному узлу, но не подтверждает работу Telegram или TikTok. При смене Wi-Fi/мобильной сети проба повторяется. [Сравнение с Nova и следующий этап](docs/NOVA-ANDROID-REVIEW.md).

## Установка

Скачайте подписанный APK из [Releases](https://github.com/privettisha/PrivetZapret-Android/releases), установите и разрешите локальное VPN-подключение Android.

1. На вкладке **DNS** вставьте полный адрес вашего сервера: `https://…/dns-query/…`, `tls://…:853`, `dot://…` или имя из «Частного DNS» Android.
2. При необходимости укажите **резервный DoH**. Если DoT/853 недоступен, приложение попробует именно эту HTTPS-ссылку. Личные ключи DoT и DoH у PrivetDNS различаются: получить один из другого нельзя.
3. Нажмите **Сохранить DNS**, затем **Подключить** на главной. Система показывает значок VPN: обработка происходит на устройстве.

Для Telegram после запуска VPN нажмите **Подключить Telegram** и подтвердите добавление SOCKS5-прокси в Telegram. Если ссылка не открылась, добавьте его вручную: `127.0.0.1`, порт `14430`, тип SOCKS5, без логина и пароля. Прокси доступен только на этом телефоне и только пока PrivetZapret подключён. Для отключения прокси используйте настройки Telegram. Прокси рассчитан на сообщения и медиа; звонки проверяются отдельно.

По умолчанию выбран публичный Cloudflare DoH. Ваш PrivetDNS будет использоваться после сохранения личной ссылки. Никакие реальные пользовательские ключи в репозитории не содержатся.

## Режимы

- **Обход + DNS:** IPv4 и IPv6 приложений проходят через локальный TUN → SOCKS → ByeDPI. Запросы UDP/TCP на порт 53 перехватываются и передаются выбранному зашифрованному DNS. TCP и UDP приложений обрабатываются ByeDPI; для UDP/443 применяется отдельный профиль.
- **Только DNS:** в VPN направляется только виртуальный DNS `10.111.0.2/32`, выданный Android. Остальной трафик идёт обычным путём. Жёстко заданные DNS других приложений не перехватываются.
- **Профили обхода:** автоматическая последовательность disorder/TLS-record split, простое разделение TCP и разделение TLS. Это профили ByeDPI; здесь нет портирования Windows WinDivert или привилегированного nfqws.
- **QUIC-приманка из версии ПК:** экспериментальный переключатель в настройках. Встроены те же 1200 байт Google QUIC Initial, что использует настольный PrivetZapret; ByeDPI отправляет 11 приманок только перед первым UDP/443 пакетом каждого соединения. Обычный профиль отправляет две короткие приманки также только в начале. Это не перенос `nfqws2`: в Android нет его выборки по доменам QUIC и приёмов `tcp_md5`/`multidisorder`. Если включено «Принудительно использовать TCP», QUIC-переключатель не действует.

При успешном переходе на резервный DoH он используется 60 секунд, затем основной сервер проверяется новым запросом. Никакого неявного перехода на открытый UDP/53 нет. Если оба сервера недоступны, DNS-запрос получает SERVFAIL. Старт VPN требует успешного тестового разрешения `example.com`.
Для DoT все указанные начальные IP-адреса пробуются по очереди с сохранением имени для проверки TLS-сертификата.

## Где проходят границы

DoH использует HTTPS, обычно TCP/443, и может помочь при блокировке DNS/53 или DoT/853. Приложение **не открывает запрещённый порт** и не может само превратить любой DoT-сервер в DoH. Если заблокированы IP или HTTPS самого DNS-сервера, нужен другой доступный сервер/маршрут.

Локальные приёмы DPI не дают универсального обхода IP-блокировок, белых списков, активного распознавания или отключения связи. Нет удалённого VPN-сервера, смены внешнего IP или обещания «невидимости». Шифруется DNS, а содержимое обычного трафика защищают сами приложения через HTTPS/TLS. Провайдер видит IP-адреса, время и объём соединений.

Telegram: сообщения, медиа и звонки требуют отдельных проверок. YouTube: запуск страницы не равен воспроизведению видео — нужны проверки googlevideo, перемотки и длительных роликов. TikTok: ограничения платформы по SIM, региону и аккаунту могут сохраняться.

В настольном PrivetZapret Telegram Desktop использует отдельный локальный MTProto/WebSocket-прокси. Android теперь содержит адаптированный SOCKS5/WebSocket-прокси: Telegram Android передаёт ему свои соединения по SOCKS5, после чего прокси пробует WebSocket к DC2/DC4 и при отказе прямой TCP. Это начальное покрытие, не полный набор резервных маршрутов ПК-прокси; другие DC могут не пройти. Приманка QUIC относится прежде всего к TikTok/видеотрафику и не заменяет Telegram-прокси.

Android обычно допускает одно VPN-приложение на пользователя. Строгий системный «Частный DNS» и встроенный DoH браузера могут обходить выбранный DNS-профиль. Если требуется именно DNS приложения, отключите собственный защищённый DNS браузера и строгий профиль «Частного DNS» в системе. App не меняет эти настройки за пользователя. Always-on и блокировка соединений без VPN пока не поддерживаются. Автозапуска после перезагрузки нет. После отзыва VPN-разрешения или завершения процесса Android возвращает обычную сеть; это не kill switch.

## Конфиденциальность

- Профиль зашифрован AES-GCM, ключ находится в Android Keystore. Резервное копирование приложения отключено.
- Нет аналитики, аккаунта, собственного сервера телеметрии или экспорта истории запросов.
- Тест DNS отправляет `example.com` выбранному серверу. URL с личным ключом не выводится в статус или сообщения об ошибках.
- Сертификаты и имена DoH/DoT проверяются; перенаправления DoH запрещены; собственные корневые сертификаты не устанавливаются.
- Для первого подключения нужно определить IP сервера. Можно указать IP основного сервера вручную, сохранив исходные SNI и проверку сертификата. Для Cloudflare/Google есть публичные bootstrap IP. Для других имён, включая отдельный резервный сервер, без подходящего bootstrap используется системное разрешение имени; это не отправка всех пользовательских DNS-запросов провайдеру.
- HTTPS-запросы приложений не расшифровываются. Само приложение исключено из VPN, чтобы не зациклить исходящие соединения.
- Java SOCKS-мост слушает только loopback и требует случайный пароль на сеанс. Внутренний native ByeDPI также слушает loopback на случайном порту; он не поддерживает SOCKS-аутентификацию. Это не граница безопасности против уже вредоносного приложения на том же устройстве.
- Telegram-прокси слушает только `127.0.0.1:14430` и не требует авторизации, как обычный локальный SOCKS5 в Telegram. Исходящие WebSocket-соединения идут через локальный ByeDPI; TLS-сертификат и имя проверяются. Прокси не записывает адреса и содержимое соединений в журнал.

## Сборка

```sh
git clone --recurse-submodules https://github.com/privettisha/PrivetZapret-Android.git
cd PrivetZapret-Android
# JDK 21; Android SDK 36, NDK 27.2.12479018, CMake 3.22.1
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

GitHub Actions собирает universal APK для `arm64-v8a`, `armeabi-v7a`, `x86_64`, запускает JVM-тесты и Android Lint. Release-подпись использует секреты `ANDROID_KEYSTORE_BASE64` и `ANDROID_KEYSTORE_PASSWORD`; ключ не хранится в Git. Для локальной release-сборки: переменные `SIGNING_KEYSTORE`, `SIGNING_STORE_PASSWORD`, `SIGNING_KEY_PASSWORD`.

Проверка на эмуляторе требует сети и отдельного тестового APK с другим UID, поскольку само приложение исключено из VPN:

```sh
./gradlew :app:installDebug :probe:connectedDebugAndroidTest
```

Проверяются реальный UDP/TCP DNS через TUN, HTTPS через локальный обход, повторные старт/стоп и режим «Только DNS». Скриншоты сохраняются в `Android/data/ru.privetdns.zapret.probe/files/screenshots` тестового эмулятора. Это техническая проверка транспорта; фактический обход в сетях РФ нужно измерять на устройствах и у операторов.
